# Open-Source Real-World Public Roads & Highways

Real-world public road coordinates, waypoints, and elevation profiles surveyed directly from **[OpenStreetMap (OSM)](https://www.openstreetmap.org/)**:
- **Source:** OpenStreetMap Foundation REST API & Overpass
- **License:** Open Data Commons Open Database License (ODbL 1.0) © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)
- **Generator Script:** `dev_tools/build_all_osm_tracks.py`

## Included Real-World Open Roads
1. **Pacific Coast Highway (California State Route 1) [OpenStreetMap]:**
   - File: `PacificCoastHighway.csv` (2,539 surveyed GPS nodes)
   - Real OSM ways for `CA 1` / Cabrillo Highway across the iconic **Bixby Creek Bridge** (OSM Way 120270844) and **Rocky Creek Bridge** (OSM Way 120271130) along Big Sur.
2. **Passo dello Stelvio (Strada Statale 38 dello Stelvio) [OpenStreetMap]:**
   - File: `PassoDelloStelvio.csv` (2,070 surveyed GPS nodes)
   - Real OSM ways for `SS 38` ascending the highest paved pass in the Eastern Alps (2,757 m / 9,045 ft) with 48 legendary switchbacks.
3. **Tail of the Dragon (US Highway 129 Deals Gap) [OpenStreetMap]:**
   - File: `TailOfTheDragon.csv` (1,109 surveyed GPS nodes)
   - Real OSM way 19413099 covering the world-famous 318 curves in 11 miles through Great Smoky Mountains along Cheoah River.
4. **Transfăgărășan (Drumul Național 7C) [OpenStreetMap]:**
   - File: `Transfagarasan.csv` (3,633 surveyed GPS nodes)
   - Real OSM ways for `DN 7C` through the Carpathian glacial valley up to Lake Bâlea and Bâlea Tunnel.
5. **Bundesautobahn A95 (Bavarian Alpine Expressway) [OpenStreetMap]:**
   - File: `AutobahnA95.csv` (2,387 surveyed GPS nodes)
   - Real OSM ways for German motorway `A 95` (Starnberg / Loisachtal) with unrestricted speed sweepers.
